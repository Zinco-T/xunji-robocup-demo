# 寻迹 · RoboCup 家庭组任务逻辑原型

导航与寻物演示，版本 2.1。用二维地图和模拟输入展示机器人从选择观察点、导航到点、视觉复核到报告结果的任务过程。

## 运行

下载仓库后，用现代浏览器打开 `index.html`。页面自带样式和脚本，无需安装依赖，也无需启动服务器。

## 操作

- 选择任务场景，点击“开始任务”运行。
- 点击“单步”观察每次状态变化，点击“重置”重新开始。
- 点击“演示”播放预设演示流程。
- 视觉区域显示合成检测框、深度与连续帧复核结果。
- 语音区域可模拟“开始找杯子”“询问状态”“播报位置”。浏览器支持语音合成时可以朗读回复。

## 当前实现范围

地图、视觉检测与语音口令输入均为模拟数据。页面展示任务调度、路径规划、候选目标复核和状态反馈逻辑，不代表真实机器人导航或视觉识别性能。

真实 ROS 2 小车、相机、麦克风与语音识别接口仍需接入和测试。语音朗读依赖浏览器和操作系统提供的语音能力。
